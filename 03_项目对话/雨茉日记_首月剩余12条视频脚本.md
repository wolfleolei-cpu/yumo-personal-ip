# 雨茉日记｜首月剩余12条视频脚本

这次补齐的是 **A线个人IP 8条＋B线视频号矩阵4条**。加上上一版已完成的8条，首月20条内容就全部有了脚本初稿。

整体采用三个要求：**前2秒有看点、先讲故事或问题、避免广告腔**。所有稿件都使用“主播孵化、直播技能培训、公会运营”等对外表达。

## 一、A线：雨茉个人IP剩余8条

### A03｜摆过夜市以后，我再也不敢小看一个小摊

栏目：《雨茉这些年》｜约45—55秒

:::writing{variant="social_post" id="73103"}
以前摆夜市的时候，我才发现，小摊看着不起眼，里面的学问还真不少。

你看到的是一个摊位，几件货。

但摆摊的人每天想的是什么？

今天摆在哪里？什么东西有人买？备多少货？卖不出去怎么办？

忙了一晚上，回头还得算算到底剩下多少。

我以前也觉得，做生意嘛，先干起来再说。

后来才发现，哪怕只是一个小摊，选品、位置、成本、客人，哪一样都得琢磨。

所以我现在看到那些每天早出晚归摆摊的人，是真不敢小看。

人家可能没学过什么商业管理，但很多经营上的道理，早就在一天天的生意里摸透了。

你们觉得，摆摊最难的是哪件事？
:::

画面：雨茉真人口播＋夜市实景或本人旧照片。没有历史影像，可以拍真实市场环境作为辅助画面，但不能冒充当年的纪实素材。

### A05｜换了这么多行业，我到底是在寻找什么？

栏目：《雨茉这些年》｜约45—55秒

:::writing{variant="social_post" id="73105"}
我这工作经历，要是写在简历上，估计人事都得问一句：你到底想干什么？

进过工厂，摆过夜市，开过服装店，做过教培、视力康复，后来又做直播。

听着是不是有点像在集邮？

可你真正去做了才知道，每个行业表面上都不一样，背后却有一些相通的东西。

你要找到需要你的人，要把事情做好，还得想办法让生意持续下去。

当然，也不是换一个行业，前面的经验就全能用得上。

该重新学的，还得重新学。

所以现在要问我：你到底在寻找什么？

我觉得，与其说是在找一个最好的行业，不如说是在不断寻找一种自己能长期做下去的经营方式。

这个答案，我到现在还在琢磨。
:::

拍摄重点：不要念励志宣言。开头可以带一点自嘲，最后一句放慢，留下人物真实感。

### A07｜为什么一个小老板越勤快，生意可能越难做大？

栏目：《一个女老板的生意经》｜约45秒

:::writing{variant="social_post" id="73107"}
小老板最容易犯的一个毛病，就是把自己用得太狠。

客户来了，自己接。

员工忙不过来，自己顶。

出了问题，自己处理。

看起来特别勤快，对吧？

可你仔细想想，如果公司里什么事都必须老板亲自上，那老板一休息，是不是整个公司都容易卡住？

我以前做过小生意，现在再看这个问题，感受就很不一样。

不是老板不能干活，而是有些事情不能永远只靠老板一个人。

能教给别人的，要慢慢教。

能形成流程的，要尽量形成流程。

老板最该琢磨的，可能不是自己今天多干了多少活。

而是明天哪些事情，不用自己盯着也能做好。

这个毛病，我觉得很多小老板都有。
:::

画面：办公桌、员工工作、真实沟通场景。关键词突出“自己接、自己顶、自己处理”。

### A08｜我现在越来越不愿意随便劝别人创业

栏目：《一个女老板的生意经》｜约45—55秒

:::writing{variant="social_post" id="73108"}
现在有人问我：我不想上班了，要不也出来做点生意？

我一般不会马上劝他创业。

因为我自己做过不少生意，知道这里面不只有自由，也有一大堆躲不开的问题。

上班的时候，你可能觉得老板很自由。

可真轮到自己经营，客户没有怎么办？成本怎么控制？业务出了问题谁来处理？

以前你不想面对的很多事情，最后都得自己面对。

当然，创业也有它值得尝试的地方。

但我觉得，不能只是因为上班太烦，就觉得当老板一定会更舒服。

你要先想清楚，自己究竟看到了什么机会，又准备承担什么风险。

创业可以有冲劲。

但不能只有冲劲。

你们身边有没有那种，一上班就想创业、一创业又怀念上班的人？
:::

画面：真人中近景，第一句话直接面对镜头。注意表现为个人经验分享，而不是劝阻所有人创业。

### A09｜一家直播公会，老板每天都在忙些什么？

栏目：《直播行业真话局》｜约40—50秒

:::writing{variant="social_post" id="73109"}
很多人以为，开一家直播公会，就是每天看看直播、看看数据。

哪有这么简单。

你想想，一个新人要开始学习直播，培训内容怎么安排？

已经开始直播的人，碰到了问题，运营怎么跟进？

团队每天忙了一大圈，最后到底有哪些地方需要改进？

这些事情，看上去都挺琐碎。

但如果流程没做好，后面就容易乱。

所以经营一家直播公会，不能只看直播间里发生了什么。

还要看镜头外面的人，是怎么配合做事的。

我倒觉得，真正值得拍给大家看的，不是老板每天有多忙。

而是一家直播公会，究竟是怎么运转起来的。

以后有机会，我就带你们看看真实的工作现场。
:::

拍摄重点：尽量用雨茉公司当天真实发生的工作补画面。稿件中涉及的培训、运营、复盘环节应先确认公司确实在开展。

### A10｜我当过主播以后，才知道镜头前最难的是什么

栏目：《直播行业真话局》｜约40—50秒

:::writing{variant="social_post" id="73110"}
做主播最尴尬的事情是什么？

你准备了一肚子话，结果镜头一打开，脑子突然空了。

我自己做过主播，所以知道，镜头前的表达和私下聊天，还真不是一回事。

平时跟朋友聊天，随便说什么都行。

可到了直播间，你不光要把话说明白，还得注意节奏、互动和现场的变化。

有时候一句话说完，没人接，你还得想接下来讲什么。

所以我现在觉得，新人学直播，第一步不是急着研究什么高深技巧。

先练习面对镜头自然地说话，能把一件事讲完整。

别小看这个基本功。

能对着镜头舒服地表达，本身就需要练习。

不信你现在打开手机，试着连续讲一分钟，看看自己会不会卡壳。
:::

画面：真人开头＋手机自拍练习画面。结尾可以引导观众尝试，增加评论和互动。

### A11｜做了这么多年生意，哪次选择最让我长记性？

栏目：《雨茉这些年》｜约50—60秒｜待真实事件确认

这一条我不建议直接虚构一个“创业最惨时刻”。我们已经知道雨茉经历过经营困难、卖房卖车等阶段，但还不知道她究竟认为哪一次选择最值得复盘。因此，先把表达结构写好：

:::writing{variant="social_post" id="73111"}
做了这么多年生意，如果让我选一件最值得复盘的事，我还真得认真想一想。

因为有些选择，当时觉得挺有道理。

过了几年再回头看，才发现自己漏算了很多东西。

【这里讲雨茉亲自确认的一次真实选择：当时做了什么、为什么这样决定。】

【接着讲后来发生的结果，以及她发现自己当时忽略了什么。】

这件事给我留下最深的印象，不是我当时有多难。

而是后来再遇到类似情况，我会先停下来，把几个关键问题想明白。

做生意有时候就是这样。

很多道理，别人跟你讲的时候，你觉得都懂。

真轮到自己做决定，才知道懂和做到，根本是两回事。
:::

这一条必须补齐真实决策和真实结果后才能拍。不要擅自写她当时的心理活动、损失数字或家庭细节。

### A12｜我为什么最后选择了直播行业？

栏目：《雨茉这些年》｜约45—55秒｜核心动机待确认

:::writing{variant="social_post" id="73112"}
我以前做过那么多行业，怎么最后偏偏做起了直播？

说实话，这个问题还挺值得聊的。

从工厂、夜市，到开店、做教培，我接触过不少不同的工作方式。

后来我也做过主播。

再到现在经营直播公会，我开始从另一个角度去看这个行业。

站在镜头前，你得学会表达、互动、处理现场问题。

到了经营端，还得考虑培训、运营、团队协作和长期发展。

同一个行业，站的位置不一样，看到的东西也不一样。

但如果你问我，为什么最后决定把这件事当成现在的事业来做？

【这里补入雨茉本人最真实的一个原因，以及当初作出决定的具体经历。】

这才是我真正想跟大家分享的答案。
:::

这条是人物故事的重要转折，不能随便替她确定创业动机。建议专门用10分钟访谈，把最后一段写成她自己的原话。

## 二、B线：视频号矩阵剩余4条

这4条按**AI配音＋真实工作素材＋字幕动效**设计。制作时不用每条重新设计版式，可以建立统一视觉模板，但要确保不同选题有不同的信息和示范内容。

### B03｜新人开播前，为什么一定要练这三个基本功？

约35—45秒｜教学型短视频

:::writing{variant="social_post" id="73113"}
第一次准备直播，先别急着研究复杂技巧。

有三个基本功，值得提前练一练。

第一，表达。

随便选一个熟悉的话题，试着对着镜头连续讲一分钟。

第二，声音。

讲话是不是太轻？语速是不是太快？自己录一段回听一下。

第三，话题衔接。

讲完一件事，下一句怎么自然接上？

可以提前准备几个有联系的小话题。

这些练习不复杂，但很适合刚开始学习直播的人。

先把话说清楚，再慢慢练习互动和节奏。
:::

镜头：手机录像→声音波形→话题卡片。结尾出现“三个基本功：表达、声音、衔接”。

### B04｜灯光、声音、画面，哪个最影响直播体验？

约30—40秒｜对比实验型短视频

:::writing{variant="social_post" id="73114"}
直播设备怎么调？别急着把所有设备都换一遍。

我们可以做三个简单对比。

第一，灯光。

同一个人、同一个位置，看看光线变化后，画面有什么区别。

第二，声音。

同一段话，分别用两种收音方式录下来，听听哪个更清楚。

第三，画面。

对比一下手机摆放位置和拍摄角度。

其实新人不一定需要很复杂的设备。

先保证能看清、能听清、画面稳定，再根据自己的直播内容慢慢调整。

与其盲目升级设备，不如先找到最影响观看体验的那个问题。
:::

镜头：必须实拍三组对比，最好使用同一台手机、相同场景。不要靠后期夸张处理伪造设备效果。

### B07｜一个人从零开始学直播，第一周可以练什么？

约40—50秒｜七天练习清单

:::writing{variant="social_post" id="73115"}
想练习直播表达，但不知道第一周该干什么？

可以先给自己安排一个七天小计划。

第一天，熟悉镜头，录一段自我介绍。

第二天，挑一个熟悉的话题，连续讲一分钟。

第三天，练习把一个话题讲成开头、中间、结尾三个部分。

第四天，调整灯光和声音。

第五天，模拟一次互动，练习怎么自然接话。

第六天，把之前的练习录屏回看，找出最明显的问题。

第七天，做一次完整的模拟开播。

不用急着跟别人比。

这一周的目标，就是先让自己熟悉镜头，知道下一步该练什么。
:::

镜头：七天卡片逐个出现，穿插短录屏、话题练习和模拟直播素材。适合制作收藏型知识内容。

### B08｜什么样的直播运营支持，才真正能帮助新人进步？

约40—50秒｜服务认知型短视频

:::writing{variant="social_post" id="73116"}
直播运营支持，难道就是每天提醒新人按时开播吗？

当然不能只看这一件事。

对于刚接触直播的人，真正需要了解的是：

遇到表达问题，有没有人帮助分析？

直播结束以后，能不能得到具体的复盘建议？

不清楚下一步练什么，有没有相应的学习安排？

还有，遇到自己解决不了的问题，应该找谁沟通？

所以评价一项直播运营服务，不能只听它介绍得多热闹。

更应该看具体提供什么、怎么提供，以及双方各自需要做什么。

把服务内容说清楚，才有助于作出适合自己的选择。
:::

镜头：真实运营沟通、培训资料、复盘界面。若雨茉公司没有开展某项服务，不得用相应画面暗示公司已经提供。

## 四、正式拍摄前，还需要完成一件关键工作

我不建议小助理把20份稿件直接打印出来，让雨茉照着念。

这样做大概率会出现一个问题：**语言很流畅，但人物没有自己的味道。**

我建议安排一次60—90分钟的访谈，重点挖出以下信息。

**雨茉深度访谈核实清单** /8

[复制访谈提纲]

这次访谈应该尽量保留雨茉的原话。很多有传播力的表达，不一定来自编剧，而可能来自她聊天时随口说的一句话。

## 五、小助理拿到脚本以后，按这个标准生产

| 环节 | 个人IP内容 | 视频号矩阵内容 |
|--------|--------|--------|
| 录制 | 雨茉真人口播 | 真实素材＋配音/字幕 |
| 剪辑 | 保留人物情绪与停顿，适度加B-roll | 按知识点进行结构化剪辑 |
| 单条长度 | 约40—60秒 | 约30—50秒 |
| 字幕 | 简洁、易读，重点词突出 | 教学清单、关键词和步骤 |
| 结尾 | 自然讨论，不强行引流 | 内容总结或实用提醒 |
| 审核 | 重点核对真实经历 | 重点核对知识准确性、服务描述及素材授权 |
| 发布 | 按平台分别处理标题与封面 | 交由现有视频号矩阵运营团队审核发布 |

后续生产系统需要实现的是：选题进入任务库后，自动完成脚本排版、配音、素材整理、初剪、字幕和封面草稿；小助理只负责补充素材、修改关键画面、人工审核及发布协调。

## 六、下一步执行顺序

现在不需要继续增加选题数量，应该转入真实生产验证。

1. **访谈雨茉，核实20份脚本**
   
   重点完成A11、A12，并从她的真实故事里补充更有冲突的细节。
2. **先拍A01、A02、A04**
   
   验证雨茉面对镜头的表现、说话习惯和脚本适配度。
3. **同时制作B01、B02两条矩阵视频**
   
   不依赖雨茉本人出镜，测试素材、AI配音、字幕和自动剪辑能否形成完整成片。
4. **完成5条样片后统一复盘**
   
   重点看成片质量、雨茉是否自然、脚本修改量、单条人工耗时及实际运行成本，再继续完成剩余15条。

**到这里，首月20条视频已经完成第一轮内容策划和脚本设计。**

但我认为决定项目最终效果的关键，不是这些稿子写得有多工整，而是下一步能不能把雨茉真正有特点的经历、语言习惯和经营判断融进去。

首批5条样片一旦验证成功，后面才值得正式启动自动化批量生产。
